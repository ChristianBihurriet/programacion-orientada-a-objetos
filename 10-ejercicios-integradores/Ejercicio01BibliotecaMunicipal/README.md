# Proyecto 01 — Biblioteca municipal

Construye una aplicación de consola que gestione ejemplares, usuarios y préstamos. Debe impedir prestar un ejemplar no disponible, limitar préstamos por usuario, registrar devoluciones y listar retrasos a partir de una fecha de referencia.

No se indica la estructura de clases. Antes de programar, entrega un pequeño diagrama con multiplicidades y una lista de invariantes. Prueba alta duplicada, préstamo imposible, devolución y usuario sin préstamos.
