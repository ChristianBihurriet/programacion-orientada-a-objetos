# Proyecto 03 — Gestión académica

Gestiona alumnado, módulos, matrículas y calificaciones. Debe calcular medias solo cuando existan notas, evitar matrículas duplicadas y generar un informe por alumno y otro por módulo.

Define primero casos de uso y reglas. Incluye pruebas manuales para alumno sin notas, nota límite, matrícula duplicada y varios alumnos en un mismo módulo.
