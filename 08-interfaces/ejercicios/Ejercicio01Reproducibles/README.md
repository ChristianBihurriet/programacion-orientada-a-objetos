# Ejercicio 01 — Reproducibles (nivel esencial)

## Objetivo

Definir un contrato común para clases diferentes y utilizarlo como tipo de referencia.

## Requisitos

1. Define `Reproducible` con el método `void reproducir()`.
2. Crea `Cancion` con título y artista.
3. Crea `Podcast` con nombre y número de episodio.
4. Ambas clases deben implementar `Reproducible` y mostrar sus propios datos al reproducirse.
5. Guarda una canción y un pódcast en un `Reproducible[]` y recórrelo.

## Comprobación mínima

El bucle debe reproducir ambos elementos sin comprobar sus clases concretas. Los métodos implementados deben declararse `public`.
