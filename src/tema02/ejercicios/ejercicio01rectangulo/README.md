# Ejercicio 01 — Rectángulo (nivel esencial)

## Objetivo

Practicar constructores, sobrecarga y métodos con retorno.

## Requisitos

1. Crea `Rectangulo` con los atributos `base` y `altura`.
2. Escribe un constructor que reciba ambos valores.
3. Sobrecarga el constructor con una versión que reciba solo `lado` y asigne ese valor a base y altura.
4. Implementa `calcularArea()` y `calcularPerimetro()`.
5. Crea en `main` un rectángulo y un cuadrado y muestra sus resultados.

## Comprobaciones mínimas

- Base 3 y altura 4: área 12 y perímetro 14.
- Lado 5: área 25 y perímetro 20.

## Archivo inicial

Completa [`Main.java`](Main.java) sin eliminar la declaración de paquete:

```java
package tema02.ejercicios.ejercicio01rectangulo;
```
