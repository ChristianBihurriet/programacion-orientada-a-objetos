# Ejercicio 01 — Libro (nivel esencial)

Crea una clase `Libro` con título, autor y número de páginas. Crea dos objetos, asigna sus estados y haz que cada uno muestre una ficha mediante un método. Comprueba que cambiar un libro no altera el otro.

Caso de prueba: «El Quijote», «Miguel de Cervantes», 863 debe mostrar los tres datos.
