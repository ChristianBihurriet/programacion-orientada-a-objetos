# Ejercicio 01 — Libro (nivel esencial)

## Objetivo

Practicar la diferencia entre una clase y los objetos creados a partir de ella.

## Requisitos

1. Crea una clase `Libro` con los atributos `titulo`, `autor` y `numeroPaginas`.
2. Añade un método `mostrarFicha()` que muestre los tres atributos.
3. En `main`, crea dos objetos `Libro` mediante `new Libro()` y asigna valores diferentes a sus atributos.
4. Muestra las fichas de ambos libros.
5. Cambia el título de uno de ellos y comprueba que el otro no cambia.

## Comprobación mínima

Uno de los libros debe representar «El Quijote», de Miguel de Cervantes, con 863 páginas. En este tema todavía no es necesario utilizar constructores con parámetros ni atributos `private`.
